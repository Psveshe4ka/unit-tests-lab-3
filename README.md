## Правило (Варіант 1)
Функція `deliveryCost(weightKg, sameCity)` розраховує вартість доставки:
- Базова вартість: 40 грн.
- Кожен повний кілограм понад 1 кг додає 15 грн.
- Доставка у своєму місті дає знижку 20% від підсумку.
- Вага 0 або від'ємна викидає виняток `IllegalArgumentException`.
